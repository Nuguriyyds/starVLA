## 固定配置

- 从现有工程 A 视图均匀选择 32 个已有合法窗口；未重扫全量、未改公共源数据。
- 使用同一批窗口训练和评测，目的为检验小数据可学习性，不评价泛化。
- 新 run 使用 `umi-logical-boundary-slack-v1`，边界余量 1 ms，匹配容差维持原值。
- 从 Qwen3-VL-2B-Instruct 初始化 VLM，动作头重新初始化；不继承上轮四步 checkpoint。
- 模型、动作表示与固定工程统计量沿用现有方案；batch=1，累积=2，32 窗口共消费 400 次（12.5 个数据遍历）。
- AdamW 参数沿用工程方案：VLM LR 1e-5，其他参数 LR 1e-4；warmup 10 次后线性衰减，200 次结束。
- 第 0/50/100/150/200 次更新评测全部 32 个窗口，每个窗口的 FM 噪声与动作生成 seed 固定；评测前后恢复训练随机状态。
- 结束保存一次 basic。固定评测误差由反归一化后的预测计算；保持状态基线先反归一化 state，不能把 normalized state 直接当 normalized action。

## 一次有针对性的输出诊断

从已保存的预测和 checkpoint 读取最终动作解码器末层 bias，并用记录的 seed、相同设备和 dtype 重建初始噪声。
这 32 个样本中，`预测 - (初始噪声 + bias)` 的最大绝对值为
**9.54e-07**，RMS 为
**9.94e-08**。

诊断依赖已检查的推理路径：eval 模式的视觉编码在动作头第一次 `randn` 前不采样随机数。
该结果强烈提示动作输出已退化到主要保留初始噪声、加一个常量偏置。
当前解码器使用 `Linear → ReLU → Linear`，应优先检查解码器激活和梯度；
本轮没有记录其中间激活，所以**不把“所有 ReLU 全部死亡”写成已经证实的根因**。

本轮不改模型结构、不追加更新次数、不扩大数据，也不改通信环境。
下一项应检查动作解码器的数值尺度、激活与梯度流，再决定修复方式。
视频工程容差回归已完成，无需为此继续追查微秒阈值。
